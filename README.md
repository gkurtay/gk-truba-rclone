# GK-TRUBA-RCLONE

Public documentation site for the **GK-TRUBA-RCLONE** personal OAuth client.

The client is used by its owner to transfer, back up, restore, list, and verify
the owner's own files between TRUBA HPC systems and Google Drive using
[rclone](https://rclone.org/).

This repository contains only the public landing page and privacy policy.
It does **not** contain OAuth client secrets, refresh tokens, rclone configuration
files, research data, or credentials.
