Privacy Policy

Effective date: 25 September 2026

GK-TRUBA-RCLONE is a personal, single-user OAuth client used only by its owner for file transfer, backup, restoration, listing, and integrity checking between the owner's TRUBA high-performance computing environment and the owner's Google Drive account through rclone.

Google user data accessed

When authorized by the owner, the application may access Google Drive file metadata and file contents as required to perform owner-initiated file operations such as listing, uploading, downloading, copying, and integrity verification.

How data is used

Google Drive data is used solely to perform file-management actions explicitly requested by the owner. The application is not offered to third parties and does not use Google user data for advertising, profiling, resale, or unrelated analytics.

Data sharing

Google user data is not sold. The application does not intentionally share Google user data with third parties. Data moves between the owner's Google Drive account and computing systems controlled or used by the owner as part of the owner's research workflow.

Data storage and security

OAuth credentials and rclone configuration are maintained in the owner's computing environment. Access is controlled by the owner's Google account authorization and the security controls of the computing systems used by the owner.

Data retention and deletion

The application itself does not maintain an independent user database. Files remain in Google Drive or the owner's computing environment until the owner deletes or moves them. OAuth access can be revoked by the owner through Google Account security settings.

Limited Use

Use of information received from Google APIs will adhere to the Google API Services User Data Policy , including the Limited Use requirements.

Contact

Questions about this personal OAuth client may be raised through the project's public GitHub repository: github.com/gkurtay/gk-truba-rclone .
